Major product direction

Adaptive Skill Intelligence

Skills can become more than matched runbooks. The target system combines external knowledge with verified task experience, reflects on what worked under which conditions, and accumulates a reusable individual capability asset for future comparable tasks.

It resolves task-local competence roles, discloses the smallest useful procedure, joins use with real outcomes, maintains contextual beliefs with uncertainty, and promotes only independently evaluated, reversible changes.

Honest status boundary
  • Scoped discovery, receipts, proposal-mediated mutation, guards, lifecycle tooling, and virtual-session foundations exist.
  • Outcome attribution, contextual beliefs, relationship-first consolidation, evaluator routing, and progressive promotion remain design and implementation work.
  • Broad autonomous self-improvement is not claimed implemented or active.

Capability map

What the harness owns

Each card separates the public source contract from the evidence that still matters. A mechanism can be implemented without being proven under every provider, restart window, operating-system boundary, or long-horizon workload.

Ingress

Exact channel identity

Telegram and Discord inputs pass allow-list and exact platform, account, channel, and user resolution before durable admission.

Needs per-account and per-channel provider-visible smoke evidence.
Runtime

Durable bounded work

Queue leases, retries, stale recovery, admission controls, and global, agent, channel, and lane bounds isolate interactive and background work.

Needs joined crash, overload, fairness, and soak evidence.
Backend

Codex execution boundary

Plans, preflight, app-server execution, terminal state, concrete session continuity, and provider-scoped homes are explicit and receipted.

Backend upgrades require protocol and provenance proof.
Continuity

Virtual sessions

A stable task identity can span compact, resume, and concrete-session rollover while carrying a bounded working set.

Needs end-to-end rollover and restart through final delivery.
Channels

Replies, progress, and actions

Commands, normal replies, bounded progress, media delivery, and guarded connector-approval actions share identity and delivery contracts.

Rendering and interaction behavior remains channel-specific.
Background work

Workers, cron, and delegation

Durable jobs, cron evaluation, watchdogs, exact subagent ownership, bounded mailboxes, and master-only final synthesis are explicit surfaces.

Needs reboot, real-effect, and heterogeneous-provider evidence.
Memory

Adapter-owned recall

Recall, lifecycle capture, proposals, approved writeback, imported snapshots, and per-agent compartments are receipt-backed adapters.

Fallback behavior is not full graph-memory parity.
Procedural memory

Skill runtime foundations

Skills are scoped, indexed, revisioned, selected with receipts, guarded before controlled mutation, and managed reversibly.

Adaptive outcome-linked learning remains a design direction.
Planning

Layered task authority

Codex owns in-turn decomposition; optional durable plans own milestones and evidence; the runtime owns budgets, effects, continuation, fairness, and finals.

Needs joined scope, replan, budget, and terminal scenarios.
Operations

Audit and recovery

Receipts, trace reconstruction, health, repair, backup, canary, rollback, and migration controls make decisions inspectable.

Receipts do not substitute for restore or provider recovery drills.
Security

Fail-closed trust boundaries

Bounded untrusted context, secret isolation, external-effect gates, encrypted-vault primitives, and public-hygiene checks constrain exposure.

Live credential and network review stays operator-controlled.
Compatibility

Dry-run migration

Legacy agents, prompts, skills, sessions, memory snapshots, and compatible state can be planned and imported with conflict policies and receipts.

Every real source still needs its own dry run and rollback boundary.

Verification

Claims stop where evidence stops

The right verification level follows the blast radius. Cross-cutting changes to identity, routing, skills, memory, planning, continuation, effects, or final delivery need whole-task evidence before promotion.

Contracts

Schemas, configuration, identity derivation, compatibility, and deterministic decision tables.

Focused tests

Local state transitions, validation, matching, serialization, and error handling.

Integration

Immediate producer/consumer boundaries such as queue-to-runtime or effect-to-receipt.

Scenario / replay

Exact identity, virtual session, backend, effects, restart, outbox, and terminal behavior in one joined task.

Controlled live

Provider presentation, real routing, service persistence, resource use, and bounded cohort soak.

Delivery path

From source foundations to earned autonomy

Every expansion of behavior or authority is a versioned deployment. Observation and proposals may become increasingly automatic; broad, privileged, or cross-agent change requires stronger independent evidence.

Correct and observe

Remove unsafe attribution, compile exact contracts, and compare new policies without changing prompts, effects, learning, or delivery.

Join and evaluate

Connect effects and outcomes, calibrate contextual beliefs and evaluator cost, and test held-out behavior plus downgrade.

Promote narrowly

Activate one reversible low-risk cohort with explicit authority and provider-visible evidence before any widening.
