Self-hosted agent runtime

Agent Harness Core

AHC connects Telegram, Discord and a local CLI to an AHC-managed Codex app-server backend. It owns conversation identity, durable tasks, Python workspaces, memory, tools and delivery independently of model threads.

Pre-release · Python 3.14+ · Linux, including WSL. Source checks, installed packages and live deployment acceptance remain separate claims. Updated 2026-11-08.
